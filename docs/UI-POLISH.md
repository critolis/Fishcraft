# Fishcraft 0.9.0 — UI refinements

The user's recording review approved these refinements and clarified that the apparent tooltip clipping was only the recording boundary. Tooltip ownership and anchor logic are unchanged.

## Readability and hierarchy

General Settings has a Text size control independent of UI scale: Compact uses the original requested font sizes, Comfortable adds one pixel (default), and Large adds two. Body labels and editable fields update immediately; headings above 16 px and radial labels remain fixed. The preference is per character. Changes are guarded during combat. Secondary text has increased contrast, radial labels use an outline and stronger shadow, and orb hover uses the existing glow artwork in a slightly larger, restrained halo. The six actions, radii and animation timings are unchanged.

The main heading identifies the active page; Fishcraft branding is smaller. A gold sidebar marker and blue selection background replace the leading selection bullet. Secondary controls and cards use subdued borders; selected navigation and key actions retain gold accents. The optional tracker is 12 logical pixels taller for larger body text.

## Cooking

The existing live `Advice()` appears in an 80 px Next step card above the recipe list. It still handles unreadable skill, missing recipe knowledge, carried fish, training caps and unsupported levels. Four recipe rows fit below it. Estimated / Have / Left use independent right-aligned columns. This release changes presentation, not counts or recommendation logic.

## Locations

Click the zone selector to open a raised, opaque child panel within the main window. Search is case-insensitive, trims surrounding whitespace and treats pattern characters literally. Six matching zones are shown per page; Previous/Next reaches the complete current scope. Enter selects the first visible match; an empty result does not change the current zone. Escape from the search field closes it. Selecting a zone, changing sections or closing the main window also dismisses it and clears keyboard focus.

When arriving from a fish or recipe, the picker lists only that fish's known reference or personal locations. All locations removes that restriction while retaining the selected zone when possible. Current location remains a direct action. Fish rows show cached item art or a fish-symbol fallback, their name, and a compact confidence label. Personally caught quantities refer to the selected zone, not lifetime catches elsewhere. Reference listings remain distinct. Pagination is hidden for a single page; notes follow the shorter list.

## Statistics

Eight cards use semantic artwork: clock, hook, fish, checkmark, fish with clock, stopwatch, logbook and a collection of cards. The new symbols and dropdown chevron are original vector-style shapes generated by `tools/build_media.py`, shipped as transparent 128 × 128 RGBA TGA textures. Values and metric definitions are unchanged.

## Verification

160 offline behavioral tests pass, including eight new UI/navigation regressions. Artwork was inspected at its 32 px display size. Approximate frame-derived layouts were reviewed at the largest text setting with a substitute font; they cannot certify WoW hit testing, the native font or actual rendering. In-client checks should cover all three text sizes, long fish names and advice, picker typing/selection/dismissal, tooltip placement at the full screen boundary, and radial readability against bright water.
