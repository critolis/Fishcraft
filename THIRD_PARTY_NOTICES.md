# Licensing and provenance

## Original project material

Fishcraft's original Lua code, documentation, tests, development tools and
generated UI artwork are covered by [GPL-3.0-only](LICENSE).
Copyright (C) 2026 Fishcraft contributors. The maintainer confirmed GPLv3 for
this preparation; no permission for later GPL versions has been added.

All 15 bundled `Media/*.tga` textures are generated by
[`tools/build_media.py`](tools/build_media.py). Its source is included in the
repository and matching source archive. It constructs the artwork with drawing
primitives; it does not import game textures or reference-image pixels.

## Blizzard material: referenced, not bundled

Fishcraft refers to native item icons, backdrop textures, masks and the client's
font through WoW API values and `Interface`/`Fonts` paths. No Blizzard texture,
font, sound or executable is bundled. The project license does not cover those
assets, game names or trademarks. World of Warcraft belongs to Blizzard
Entertainment; Fishcraft is an independent addon.

The README also embeds screenshots and a radial-menu GIF from the maintainer's
public CurseForge gallery. Those media files remain hosted on CurseForge and
are not included in the repository or release archives. Game imagery shown
within them is not relicensed under GPL by this project. See
[media provenance](docs/SCREENSHOTS.md) for the original links.

## Code references and dependencies

No vendored addon library or separately licensed copied source was identified
in the reviewed tree. Runtime dependencies are WoW's provided APIs only.
The compatibility research records API examples from other addon projects and
the Blizzard UI source mirror; these are references, not bundled components.
See [compatibility research](docs/COMPATIBILITY.md) and
[data provenance](docs/DATA.md). This inspection cannot independently prove
the authorship of every line; preserve any additional notices if other source
material is introduced.

Development-only dependencies are installed separately: Lupa (MIT, with Lua's
own notices) and Pillow (HPND and its bundled-component notices). GitHub Actions
are used by reference. None is redistributed in the addon or source ZIP.

## Reference data

`Data/Forever.lua`, `Data/Optimizer.lua` and `Data/Discoveries.lua` contain
selected item/recipe identifiers, names, location associations and guide-derived
numbers, with source URLs and research dates. The sources include Wowhead's
Forever item/spell pages and profession guides. Fishcraft does not bundle their
page text, images or complete databases. GPL applies to Fishcraft's original
implementation and documentation, not to an underlying third-party database or
website. Retain these citations; new bulk imports require a separate rights
review. No redistribution blocker was identified in the files inspected.

## Release source availability

Each build creates both an installable ZIP and a matching source ZIP. Distribute
the source ZIP beside the installable package so the artwork generator and
build tools remain available. See [release instructions](docs/RELEASING.md).
